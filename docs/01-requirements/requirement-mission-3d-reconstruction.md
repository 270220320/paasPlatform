## 1. 项目背景与目标

### 1.1 业务背景

AiFlow 已支持飞行计划下发、下属若干任务（执行记录）与司空侧媒体回传。作业人员需要把某次任务采集的照片一键做三维重建，并在该任务行内直接查看结果，避免跳转到司空控制台或资源库二次查找。

现有平台仅有资源库「模型重建」占位（同步假成功、无真实引擎、无任务侧入口）。司空侧能力拆分明确：

- **重建编排**：司空 OpenAPI / 后端模型重建接口（异步）
- **前端 paas.js**：不提供模型展示组件，不可作为结果查看器

### 1.2 项目目标

1. 在飞行计划详情中，**每一个已采集到图片的任务行**提供「三维重建」按钮。
2. 重建所用图片资源**存放在司空服务内**，平台通过司空接口查询/引用（如飞行任务资源文件夹、媒体列表等），**不依赖本平台本地落盘图片**。
3. 基于上述司空侧资源调用司空重建能力完成 `model_3d`。
4. 重建进度与结果挂在对应任务行展示；成功后以与图片/视频类似的缩略入口打开浏览器内 3D 预览。
5. 本期重建参数固定默认，不提供高级配置 UI。

## 3. 关键业务流程

```text
用户打开飞行计划详情
  → 列表展示该计划下若干任务（执行记录）
  → 后端/前端经司空接口判断该任务是否已有图片资源（资源在司空服务内）
  → 有图片的任务行：展示「三维重建」按钮
  → 用户点击某任务行的重建
  → 后端校验：任务存在、司空侧资源可引用、无进行中的同任务重建
  → 通过司空接口定位该飞行任务图片资源（如 task_folder_id / 媒体列表）
  → 调用司空模型重建（model_3d + 默认参数，含 b3dm）——重建引擎直接使用司空侧资源，无需下载到本平台
  → 返回 job，该任务行展示 pending/running
  → 后端异步轮询司空模型状态直至 success/failed
  → 成功：该任务成果区出现模型入口；点击后浏览器内预览（预览地址亦由司空模型详情接口取得）
  → 失败：展示失败原因，允许重试
```

**默认重建参数（本期写死，可配置项进配置文件而非 UI）**

| 项 | 默认值 | 说明 |
|----|--------|------|
| reconstruction_type | `model_3d` | 仅三维 |
| quality_level | `medium` | 中质量（可配置覆盖） |
| reconstruction_mode | `normal` | 普通场景 |
| simplified_factor | `0.2` | 司空建议值 |
| generate_model_formats | `["b3dm"]` | 便于浏览器 Cesium 展示 |
| wkt / 坐标系 | 平台默认或司空项目默认 | 详设时按 OpenAPI 必填项落配置 |

## 4. 核心功能点清单

| 编号 | 模块 | 功能点 | 优先级 | 功能描述 |
|------|------|--------|--------|----------|
| F-01 | 计划 | 可重建任务识别 | P0 | 经司空接口确认该任务有图片资源后展示重建按钮；无则不展示或禁用 |
| F-02 | 计划 | 发起三维重建 | P0 | 按任务（execution）一键创建重建；防同任务重复提交 |
| F-03 | 对接 | 司空资源获取 | P0 | 通过司空接口获取飞行任务图片资源引用（资源留在司空，本平台不落原图） |
| F-03a | 对接 | 司空重建调用 | P0 | 将司空侧资源引用交给司空重建接口发起异步 `model_3d` |
| F-04 | 对接 | 状态同步 | P0 | pending→running→success/failed；失败落原因 |
| F-05 | 计划 | 状态与结果展示 | P0 | 任务行/成果区展示进度与模型入口，形态对齐媒体缩略 |
| F-06 | 前端 | 浏览器 3D 预览 | P0 | 自建查看器加载 b3dm/3D Tiles；弹层交互对齐图片/视频预览习惯 |
| F-07 | 计划 | 失败重试 | P1 | 失败后可再次发起 |
| F-08 | 运维 | 默认参数配置化 | P2 | 质量/坐标系等进后端配置，无 UI |

### 优先级定义

- **P0**：核心流程，缺失则项目不可交付
- **P1**：重要功能，可延期但不影响核心流程
- **P2**：锦上添花，可后续迭代

## 5. 非功能需求

| 类别 | 需求描述 | 验收指标 |
|------|----------|----------|
| 性能 | 发起接口快速返回，重建异步 | 发起 API P95 &lt; 3s；不阻塞计划详情主查询 |
| 性能 | 预览首屏可接受 | 模型 tiles 可渐进加载；不要求整包一次下载 |
| 安全 | 重建与预览鉴权 | 无任务权限不可发起/查看；司空 token 仅后端持有 |
| 可用性 | 状态可感知 | 重建中刷新详情可见进度；失败有文案 |
| 兼容性 | 浏览器 | 支持桌面 Chrome / Edge 近两个大版本（WebGL） |
| 可靠性 | 幂等 | 同任务存在进行中重建时拒绝重复创建 |

## 6. 验收标准

| 验收项 | 通过标准 |
|--------|----------|
| A1 入口位置 | 计划下任一有采集图片的任务行均有「三维重建」；无图片的任务行无可用入口 |
| A2 媒体约束 | 经司空接口查无该任务图片资源时，按钮不出现或禁用并提示 |
| A3 发起成功 | 点击后产生重建任务，状态为 pending/running |
| A4 状态闭环 | 最终变为 success 或 failed；failed 有原因 |
| A5 结果展示 | success 后该任务成果区出现模型入口（形态类似图片/视频缩略） |
| A6 浏览器预览 | 点击可打开三维模型预览并可旋转/缩放浏览 |
| A7 本地媒体 | 不提供本地上传重建入口 |
| A8 参数 | 发起过程无参数配置表单；使用默认三维参数 |
