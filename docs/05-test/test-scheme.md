### 3.2 核心业务流程测试

- **主流程 1 · 首次飞行**：登录 → 建航线并发布 → 建设备绑定 → 新建立即任务 → 执行 → 看板查看统计
  - 覆盖：U-001/030/031/060/061/040/041/010
  - 关键验证点：任务状态 pending→running→completed；看板 sortieCount+1
- **主流程 2 · 媒体采集**：执行任务 → 媒体上传 → 列表倒序 → 下载/预览 → 回收站还原
  - 覆盖：U-040/050/051
  - 关键验证点：媒体按 createdAt 倒序；下载 URL 可用

## 4. 接口测试方案

| 接口 | 请求方式 | 测试工具 | 验证点 |
|------|----------|----------|--------|
| `/api/v1/auth/login` | POST | Postman | 正确/错密/禁用账号；Token 载荷 |
| `/api/v1/members` | POST/GET | Postman | 账号唯一性(10003)；权限校验 |
| `/api/v1/roles/{id}` | PUT | Postman | locked 角色 10005；全量覆盖语义 |
| `/api/v1/annotations` | CRUD | Postman | GeoJSON 类型一致性(30002)；locked 文件夹(30003) |
| `/api/v1/annotations/sync` | POST | Postman | 无设备(30004)；任务进行中(30005) |
| `/api/v1/waylines` | CRUD | Postman | 名称超长(40002)；类型白名单(40005)；删除被引用(40004) |
| `/api/v1/missions` | POST | Postman | 设备/航线校验(50002/50003)；参数缺失(50005) |
| `/api/v1/missions/{id}/actions/*` | POST | Postman | 状态机非法转移(50004)；执行中删除(50007) |
| `/api/v1/library/media` | CRUD | Postman | 配额预检(60002)；上传凭证(60003) |
| `/api/v1/devices/bind` | POST | Postman | 绑定码校验(20002)；SN 冲突(20001) |
| `/api/v1/algorithms/{id}` | PUT | Postman | not_opened 启用(80002) |

## 9. 回归测试策略

- **全量回归**：P0 缺陷修复后、版本发布前
- **增量回归**：每次合并触发后端 `mvn test` + 前端 `npm test`
- **自动化回归**：
  - 后端 Service 单测（Mockito，覆盖状态机/错误码）
  - 前端纯函数单测（Vitest，覆盖设备映射/限飞区存储）
  - 目标自动化比例：核心逻辑 ≥ 60%
