================ 二、API 依赖图谱（按服务分组）================

================ 三、保存链路时序还原 =================
  1. 浏览器端编辑完成 → libwpmz WASM 生成 KMZ Blob（new File([blob], fileName)）
  2. POST /pf-wayline/editor/v1/sts { object_key_prefix, expire:900 } → 拿 OSS STS
  3. 浏览器直传 OSS（对象 key = /dji_wpmz/...）
  4. POST /pf-wayline/editor/v1/upload { objectKey, fileName, snapshot, ... } → 注册航线，返回 waylineId
  5. 快照图 → /snapshot-upload
  ★ mock 要点：STS 接口发假凭证 + 自建"OSS"接收 PUT；upload 落盘即得 KMZ 产物

★ 保存链路实测（完整时序，与静态推断一致但协议细节全断实）：
  1. POST /pf-wayline/editor/v1/sts {object_key_prefix:"<工作空间uuid>", expire:900}
     → {code:0, data:{bucket:"file-storage-privatization", credentials:{access_key_id,
        access_key_secret, security_token, expire, platform}}}
  2. S3 分片直传（同域名路径，MinIO 兼容层，非独立 OSS 域名）：
     POST /file-storage-privatization/<ws-uuid>/CAPTURE-TEST.kmz?uploads=        初始化分片
     PUT  ...?partNumber=1&uploadId=...   body=Blob(1357B 空航线 / 3339B 三航点) ← KMZ 本体
     POST ...?uploadId=...               body=CompleteMultipartUpload XML       合并分片
  3. POST /pf-wayline/editor/v1/upload
     req : {kmz_object_key, wayline_name, wayline_uuid:""(新建)|已有uuid(覆盖),
            origin_wayline_uuid, editor_warnings, snapshots[], model_file_object_keys[],
            model_file_uuids[], with_megaphone, with_search_light,
            target_area_file_object_key, business_file_object_key,
            elevation_file_object_keys[], clean_collision}
     resp: {code:0, data:{ext_data, kmz_data:{survey_area_scope}, kmz_object_key,
            wayline_name, wayline_uuid}}  ← 拿到司空 uuid

================ 五、mock 可行性结论（运行时验证后）================
  1. 对象存储是同域名路径（/file-storage-privatization/），S3 兼容协议三分片端点
     → mock 无跨域/签名难点，接住 PUT 即得 KMZ 本体（实测仅 1.3~3.3KB）
  2. 瓦片地址配置下发 + 地形可缺省 → 地图层 mock 门槛极低
  3. WS 非必需 → 可完全不 mock 或仅静默心跳
  4. 需要认真回放的读接口（响应体已全部实录在 netlog）：topologies/grouped、
     map-configs、pf-wayline lists/details、pf-map elements/lists、model-list
  5. 面状航线生成仍需司空服务端（generate-*-callback），mock 环境仅线状可用

遗留小坑：编辑器要求视口≥某尺寸（小窗口反复弹分辨率警告）；虚拟飞行打点模式
（W 前进 + Space 打点）属交互行为，不影响 mock。
工具沉淀（可复用）：frontend/public/sdk-net-recorder.js（hook）+
scripts/_sdk_capture/{netlog-receiver,analyze-netlog,sign-jwt}.js
